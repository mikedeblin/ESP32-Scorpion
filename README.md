# ESP32-Scorpion

[English version](README.en.md)

Эмулятор компьютера **Scorpion ZS-256** (ZX Spectrum-совместимый, 256 КБ ОЗУ) на плате ESP32-S3:
вывод на VGA-монитор, USB-клавиатура, звук AY-3-8912 и бипер через I2S-ЦАП, TR-DOS с образами
дисков на SD-карте.

## Что работает

- Scorpion ZS-256: 256 КБ ОЗУ, ROM 2.95 (меню, Basic 128/48, теневой монитор по Magic, TR-DOS 5.03)
- VGA 640×480, 60 Гц или 50 Гц (кадр в кадр с эмуляцией), 15 цветов (с BRIGHT), FLASH
- Экран снимается «по лучу»: каждая строка — в тот такт, когда её рисовал бы ТВ. Работают
  демо-эффекты, гоняющиеся за лучом, мультиколор, полосы на бордюре
- USB-клавиатура (boot-протокол) через OTG
- Звук: AY-3-8912 + бипер, стерео ACB, 48 кГц на PCM5102
- TR-DOS: эмуляция ВГ93 (WD1793), дисководы A и B, образы `.trd` и `.scl`
- Образы с SD-карты; запись TR-DOS сохраняется обратно в `.trd` на карте
- Меню выбора дисков по F9
- Лента: мгновенная загрузка `.tap` (перехват LD-BYTES)
- Режим USB-диска: плата, подключённая к ПК разъёмом USB, видна как флешка (SD-карта или внутренняя flash)

## Подключение

### VGA через 74AC244

| ESP32-S3 | 74AC244 вход → выход | Резистор | VGA (DB15) |
|---|---|---|---|
| GPIO4 (R) | 2 → 18 | 360 Ом | 1 (Red) |
| GPIO14 (R+) | 4 → 16 | 1.5 кОм | 1 (Red) |
| GPIO5 (G) | 6 → 14 | 360 Ом | 2 (Green) |
| GPIO15 (G+) | 8 → 12 | 1.5 кОм | 2 (Green) |
| GPIO6 (B) | 11 → 9 | 360 Ом | 3 (Blue) |
| GPIO16 (B+) | 13 → 7 | 1.5 кОм | 3 (Blue) |
| GPIO7 (HSYNC) | 15 → 5 | 68 Ом | 13 |
| GPIO8 (VSYNC) | 17 → 3 | 68 Ом | 14 |

- 74AC244: ноги 1 и 19 (OE) и 10 (GND) — на землю; нога 20 (VCC) — 3.3 В **от отдельного
  стабилизатора** (от 5 В), не от шины 3.3 В платы: иначе на светлом фоне видны полосы от
  нагрузки ESP32. Керамика 100 нФ прямо между ногами 20 и 10, рядом 10 мкФ.
- Земли VGA (5, 6, 7, 8, 10) — к GND платы, коротко.
- Все 8 входов буфера должны быть подключены (к GPIO или к GND). Висящий вход 74AC
  генерирует — срыв кадровой синхронизации, полосы.
- Резисторы R/R+ (и G/G+, B/B+) соединяются вместе на контакте VGA: обычный цвет ≈ 0.55 В,
  яркий ≈ 0.68 В.
- Если BRIGHT не нужен — не ставьте резисторы 1.5 кОм и посадите входы 4, 8, 13 на GND.

### Звук: PCM5102

| PCM5102 | ESP32-S3 |
|---|---|
| VIN | 5V |
| GND | GND |
| BCK | GPIO1 |
| LCK | GPIO2 |
| DIN | GPIO9 |
| SCK | GND (ЦАП сам делает тактовую из BCK) | 

Перемычка на лицевой стороне: SCK = замкнуть (на GND).  
Перемычки на обороте модуля: FLT = L, DEMP = L, **XSMT = H** (иначе ЦАП молчит), FMT = L.

### SD-карта (SPI)

| Модуль | ESP32-S3 |
|---|---|
| 3V3 | 3V3 |
| GND | GND |
| CS | GPIO10 |
| MOSI | GPIO11 |
| CLK | GPIO12 |
| MISO | GPIO13 |

### USB

- Разъём **COM** — прошивка и Serial.
- Разъём **USB** (нативный) — клавиатура через OTG-переходник. На клонах платы должна быть
  запаяна перемычка **USB-OTG** (подаёт 5 В на этот разъём).
- **Не подключайте оба разъёма к компьютеру одновременно.**

## Сборка

### 1. Arduino IDE

- Ядро **esp32 by Espressif 3.3.12** (Boards Manager).
- Tools:
  - Board: **ESP32S3 Dev Module**
  - USB Mode: **USB-OTG (TinyUSB)**
  - USB CDC On Boot: **Disabled**
  - PSRAM: **OPI PSRAM**
  - Flash Size: **16MB (128Mb)**
  - Partition Scheme: **16M Flash (2MB APP/12.5MB FATFS)**
  - USB Firmware MSC On Boot: **Disabled**

Неправильные USB Mode, CDC On Boot и PSRAM скетч ловит при компиляции (`#error`).

> **Если прошивка падает с «MD5 of file does not match data in flash»**, включите
> **Erase All Flash Before Sketch Upload: Enabled**. Так бывает на клонах с flash
> Spansion/Infineon S25FL127S/128S (JEDEC ID `01 2018`, проверяется `esptool flash-id`):
> у неё 4-КБ стирание работает только в начале и конце памяти. Эмулятор это учитывает
> (раздел с образами ведётся блоками по 64 КБ), но обычная прошивка из IDE — нет.
> Erase All стирает и образы во flash — после прошивки залейте их заново.

### 2. ROM (обязательно)

ROM в репозитории нет: в нём чужой код (прошивка Скорпиона, Basic 48/128, TR-DOS).
Нужен файл ROM **Scorpion ZS-256 версии 2.95**, 64 КБ (проверенный: CRC32 `0C6C1EF6`).
Где взять (файл один и тот же, `scorp295-0C6C1EF7.rom`; в имени CRC с опечаткой, на самом деле
CRC32 `0C6C1EF6` — это он):
- [speccy4ever: ROM Скорпиона](https://speccy4ever.speccy.org/_SC.htm), строка «ZS-256 V.2.95» — [прямая ссылка](https://speccy4ever.speccy.org/rom/scorp295-0C6C1EF7.rom);
- [проект Scorpion ZS-256 Turbo+](https://github.com/romychs/Scorpion256TPlus/blob/main/ROM/scorp295-0C6C1EF7.rom) на GitHub.

```sh
python3 tools/rom2h.py scorp295-0C6C1EF7.rom > ESP32-Scorpion/rom_scorpion.h
```

### 3. Лента (необязательно)

```sh
python3 tools/tap2h.py game.tap > ESP32-Scorpion/tape.h
```

Без `tape.h` магнитофон пуст: `LOAD ""` ждёт, как без кассеты (Esc = BREAK).

### 4. Прошить

Открыть `ESP32-Scorpion/ESP32-Scorpion.ino`, Upload через разъём COM.

## Образы дисков

Откуда эмулятор берёт образы (`.trd`, `.scl`, в корне), по порядку:

1. **SD-карта** (FAT32). Изменения, сделанные в TR-DOS, сохраняются обратно в `.trd`
   (изменённые дорожки, через ~0.5 с после записи). `.scl` — только чтение.
2. **Внутренняя flash** (~12 МБ) — если карты нет.
3. **`disks.h`** в прошивке: `python3 tools/disk2h.py disk.scl > ESP32-Scorpion/disks.h`.

**Заливка без картридера — режим USB-диска.** Подключите к ПК **только разъём USB**
(обычным кабелем, без OTG-переходника): через ~1.5 с плата станет флешкой, на экране
«USB DISK MODE». Если вставлена SD-карта — ПК видит **карту** (как в картридере), иначе —
**внутреннюю flash**. Скопируйте файлы, «Извлечь», отключите. Внутреннюю flash перед первым
использованием отформатируйте с ПК: `sudo mkfs.vfat -I -S 4096 -n ZXDISKS /dev/sdX` (Linux).

В меню видны только файлы из корня — архив можно держать в подпапке.
При старте первые два образа по алфавиту вставляются в A и B.

## Клавиши

| Клавиша | Действие |
|---|---|
| Shift | CAPS SHIFT |
| Ctrl, Alt | SYMBOL SHIFT |
| Backspace | DELETE (CAPS+0) |
| Стрелки | CAPS+5..8 |
| Esc | BREAK |
| CapsLock | CAPS LOCK (CAPS+2) |
| Tab | расширенный режим (CAPS+SYM) |
| **F9** | меню дисков: ↑/↓ (удержание — автопрокрутка), PgUp/PgDn, Home/End; A или Enter → в A, B → в B, `<empty>` вынимает, Esc — выход |
| **F10** или Ctrl+Alt+Del | сброс Скорпиона (диски остаются) |
| **Ctrl+Alt+End** | полный перезапуск ESP32, как кнопка на плате (изменения дисков сначала сохраняются на SD; в A и B — снова первые образы) |
| **F11** | Magic (теневой монитор) |
| **F12** | перемотка ленты + `LOAD ""` (из 48 BASIC) |

## TR-DOS: коротко

- В меню Скорпиона «128 TR-DOS» — запуск `boot` с диска A (или приглашение `A>`).
- В командную строку без `boot`: «48 BASIC», затем `RANDOMIZE USR 15616`.
- Сменить дисковод: `*"B:"`. Выход в BASIC: `RETURN`.

## Ограничения

- Кадр 69888 тактов, без задержек доступа к памяти — как у Скорпиона (сверено с Fuse, MAME,
  Unreal Speccy). Тонкости не эмулируются: выравнивание M1 на чётный такт, длина INT 32 такта,
  «плавающая шина» в порту #FF. Экран и бордюр — с точностью до строки, не до такта.
- ВГ93: Read Track не реализован (TR-DOS его не использует).
- VGA по умолчанию 640×480@60 (763 точки в строке — почти стандарт); при 60 Гц каждый 5-й
  кадр Спектрума показывается дважды. Для кадра в кадр есть режим 50 Гц: в начале
  `ESP32-Scorpion.ino` поставьте `#define VGA_HZ 50` (768×625 точек, строчная 31.25 кГц —
  нестандартно, не всякий монитор покажет, часть сжимает картинку). Монитору может
  понадобиться «Авто».
